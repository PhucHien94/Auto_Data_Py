Đọc file `execution_result.json` thu được sau khi chạy test. Hãy:
1. Lọc ra toàn bộ các testcase có trạng thái `Failed`.
2. Tạo file báo cáo lỗi chi tiết gồm: Bug ID, Summary, Steps to Reproduce, Expected Result, Actual Result, Severity.
3. Xuất kết quả ra file `Bug_Report.md`.
